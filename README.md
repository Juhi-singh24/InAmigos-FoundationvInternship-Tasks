InAmigos Foundation Website

Project Overview

This project is a responsive website developed for InAmigos Foundation using HTML5 and CSS3. The website presents the foundation's mission, values, projects, and community initiatives through a clean, modern, and user-friendly interface.

Features

- Responsive design for desktop, tablet, and mobile devices
- Home section with foundation introduction
- About Us section
- Projects showcase section
- Gallery section
- Join Us section
- Contact section with social media links
- Smooth navigation between sections

Technologies Used

- HTML5
- CSS3
- GitHub Pages

Website Sections

1. Home
2. About InAmigos Foundation
3. Projects
4. Gallery
5. Join Us
6. Contact
